For development on windows

First do a "make" on Linux to generate all the *.py files.

Install:
    Install python
        Open "cmd" window.  
	Type "python"
	Install from store.
	Open installer

	    Alternate https://www.python.org/downloads

    Note: python3 and pip must be in your PATH

    Follow the instructions in install-libmvp.md to install
    the needed dll.   Put the libmpv-2.dll in 
    C:\mpv

    Open command (cmd) windows AS ADMINSTRATOR.
	Run 
	    .\win-setup.bat
	Close the window since we modified the path
