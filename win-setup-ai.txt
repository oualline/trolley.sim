# Installing Python and Required Modules for Trolley Simulator using MSYS2

This procedure will guide you through installing Python and all required modules for the trolley simulator using MSYS2 on Windows.

## Prerequisites

1. Download and install MSYS2 from https://www.msys2.org/
2. Follow the installation instructions and complete the initial setup

## Installation Steps

### 1. Update MSYS2

Open the MSYS2 MINGW64 terminal and update the package database:

```bash
pacman -Syu
```

If the terminal closes, reopen it and run the update again:

```bash
pacman -Su
```

### 2. Install All Required MSYS2 Packages

Run this single command to install all necessary packages (can be used in a shell script):

```bash
pacman -S --needed --noconfirm \
    mingw-w64-x86_64-python \
    mingw-w64-x86_64-python-pip \
    mingw-w64-x86_64-gcc \
    mingw-w64-x86_64-pkg-config \
    mingw-w64-x86_64-python-pyqt5 \
    mingw-w64-x86_64-gstreamer \
    mingw-w64-x86_64-gst-plugins-base \
    mingw-w64-x86_64-gst-plugins-good \
    mingw-w64-x86_64-gst-plugins-bad \
    mingw-w64-x86_64-gst-plugins-ugly \
    mingw-w64-x86_64-python-gobject \
    mingw-w64-x86_64-vlc
```

**Note:** The `--needed` flag prevents reinstalling already installed packages, and `--noconfirm` automatically accepts the installation.

### 3. Install Python Packages via pip

Install the required Python packages:

```bash
pip install python-vlc pyinstaller
```

### 4. Verify Installations

Check that everything is properly installed:

```bash
# Check Python version
python --version

# Check PyQt5
python -c "from PyQt5 import QtWidgets; print('PyQt5 OK')"

# Check VLC
python -c "import vlc; print('VLC OK')"

# Check GStreamer
gst-launch-1.0 --version

# Check PyInstaller
pyinstaller --version
```

### Running the Installation Script

1. Save the script as `install_trolley_deps.sh` in your MSYS2 home directory
2. Make it executable:

## Using PyInstaller

### Create a Standalone Executable

Navigate to your trolley simulator directory and run:

```bash
pyinstaller --onefile --windowed main.py
```

Options explained:
- `--onefile`: Creates a single executable file
- `--windowed`: Hides the console window (use for GUI applications)

### Create Executable with All Resources

For applications with images, videos, and sound files, create a spec file for better control:

```bash
pyinstaller --name="TrolleySim" \
    --windowed \
    --add-data="image:image" \
    --add-data="video:video" \
    --add-data="sound:sound" \
    --add-data="*.mp3:." \
    main.py
```

**Note:** On Windows/MSYS2, the separator in `--add-data` is `;` instead of `:`. Adjust accordingly:

```bash
pyinstaller --name="TrolleySim" \
    --windowed \
    --add-data="image;image" \
    --add-data="video;video" \
    --add-data="*.mp3;." \
    main.py
```

The executable will be created in the `dist` directory.

### Troubleshooting

**If you encounter GStreamer errors:**
- Ensure all GStreamer plugins are installed
- Check that the sound files exist in the correct directory
- Verify GStreamer is working: `gst-launch-1.0 --version`

**If PyQt5 doesn't work:**
- Ensure you're using the MINGW64 terminal (not MSYS2 or MINGW32)
- Verify installation: `python -c "from PyQt5 import QtWidgets; print('PyQt5 OK')"`

**If VLC doesn't work:**
- Install VLC standalone from videolan.org if needed
- Verify: `python -c "import vlc; print('VLC OK')"`

**If PyInstaller executable doesn't run:**
- Check that all resource files (images, videos, sounds) are included
- Run PyInstaller with `--debug all` to see detailed error messages
- Make sure the executable is run from a directory where it can access required DLLs
